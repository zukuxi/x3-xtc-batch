# X3 PDF 跨页拼接批量转换 XTC / XTCH

## 功能

- 多选 PDF 或选择整个文件夹，按文件名自然顺序排队。
- 选择“每 N 个 PDF 合并成一本”：例如设为 2，队列中的每两份 PDF 连续拼接并编码成**一个 `.xtc` 或 `.xtch` 文件**。ZIP 只是可选的额外批量打包，不是合并输出格式。
- 跨页连续拼接：保留每一页实际渲染的行，上一页剩余行与下一页开头继续拼接，不重叠；不足一张 X3 页面时只在整组最后补白。
- 选入 PDF 后自动生成第一张最终输出页面预览；预览直接绘制经过灰度量化/抖动处理后的像素，不显示原始彩色页面。更改参数后自动刷新。
- 目标尺寸 528 × 792，支持黑白 XTC 和 4 灰阶 XTCH。
- 支持蒙版兼容模式、单独下载每组结果、可选 ZIP 打包。
- 所有 PDF 都在本机浏览器中处理，不上传到服务器。
