# X3 PDF 批量转 XTC / XTCH

这是基于 `zukuxi/x3-xtc-converter` 现有轻量版本制作的批量版文件包。它保留 528×792 分段渲染、XTG/XTH 编码和 XTC 容器封装，新增多文件队列、文件夹选择、单文件下载、ZIP 打包和蒙版兼容渲染开关。

## 文件

- `index.html`：页面界面
- `app.js`：PDF 渲染、编码、队列处理

## 新增功能

- 通过多选框一次选择多个 PDF。
- 通过文件夹选择器导入文件夹中的 PDF（浏览器是否支持文件夹选择取决于平台；不支持时仍可多选文件）。
- 队列按顺序逐个转换，不会并行打开多个 PDF。
- 每个文件单独显示等待、转换中、完成、失败或取消状态。
- 成功文件保留单独的 XTC/XTCH 下载按钮，并可把所有成功结果打包成 ZIP。
- “蒙版兼容模式”开启时，渲染调用使用 PDF.js `print` intent；关闭时使用 `display` intent。它是切换渲染路径的兼容性尝试，并非能保证移除任何 PDF 中的所有蒙版。
- 文件在浏览器本地处理，不会上传到服务器。

## 用到的在线库

- PDF.js 5.4.624（cdnjs）
- JSZip 3.10.1（cdnjs）

因此初次打开页面和打 ZIP 时需要浏览器能访问对应 CDN。

## 替换到 GitHub Pages

1. 在仓库页面打开 `index.html`，点铅笔编辑，替换为此包中的 `index.html` 完整内容，再提交。
2. 打开 `app.js`，同样替换为此包中的 `app.js` 完整内容并提交。
3. 等 GitHub Pages 自动部署完，再打开现有 Pages 地址测试。
4. 建议先用 2 个较小 PDF 测试输出、预览和 ZIP，再测试很大的条漫 PDF。

如果希望先试用而不影响已上线网页，可以先把这两个文件上传到新分支；确认结果后再合并到 `main`。
