# X3 PDF 批量转 XTC / XTCH

## 新增功能

- 通过多选框一次选择多个 PDF。
- 通过文件夹选择器导入文件夹中的 PDF（浏览器是否支持文件夹选择取决于平台；不支持时仍可多选文件）。
- 队列按顺序逐个转换，不会并行打开多个 PDF。
- 每个文件单独显示等待、转换中、完成、失败或取消状态。
- 成功文件保留单独的 XTC/XTCH 下载按钮，并可把所有成功结果打包成 ZIP。
- 文件在浏览器本地处理，不会上传到服务器。

## 用到的在线库

- PDF.js 5.4.624（cdnjs）
- JSZip 3.10.1（cdnjs）

因此初次打开页面和打 ZIP 时需要浏览器能访问对应 CDN。
